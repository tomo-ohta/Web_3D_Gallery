# Web Tech Demo — リアルタイム3D表現ギャラリー

現在のWebブラウザ（WebGL2）で現実的に動作する、最高品質クラスのリアルタイム3D表現を
1ページで一覧・体験できる技術デモギャラリーです。全30デモがすべてブラウザ内で
リアルタイム描画され、各カード上でそのまま操作できます。

**▶ https://tomo-ohta.github.io/Web_3D_Gallery/**

## 起動方法

```bash
npm install
npm run dev
```

→ http://localhost:5175 を開く

本番ビルドは `npm run build`（出力: `dist/`、`npm run preview` で確認）。
`main` への push で GitHub Actions が `dist/` を GitHub Pages へ配信します。

アセットはフル品質のまま同梱し、**デモ単位で遅延取得**します（HDRI 2K ×3、
DamagedHelmet 2048px テクスチャ、Fox、量子化済みドラゴンメッシュ）。
最初の表示に必要なのは HTML + CSS + JS（gzip 約230KB）だけで、
残りはスクロールして見たデモの分だけ順に読み込まれます。

### 単一ファイル版

```bash
npm run build:artifact
```

`artifact/web-tech-demo.html` に、スクリプト・スタイル・モデル・HDRI をすべて埋め込んだ
**自己完結の1ファイル（約8.8MB）** を書き出します。外部への通信は Google Fonts だけです。
配信版のアセットを `tools/` のスクリプトで縮小してから埋め込みます。

| 対象 | 手法 | 効果 |
|---|---|---|
| HDRI ×3 | 線形空間でボックス縮小し RGBE で再出力（2048→512px） | 17.8MB → 1.5MB |
| DamagedHelmet | テクスチャを 1024/512px へ再エンコード＋`data:` URI 化 | 3.6MB → 1.13MB |
| Dragon | ドラゴンのメッシュのみ抽出し位置int16/法線int8に量子化 | 6.1MB → 1.7MB |

glTF の画像を `data:` URI にしているのは、`bufferView` のままだと GLTFLoader が
`blob:` URL を作って読み込み、埋め込み配信先の CSP で遮断される恐れがあるためです。

ドラゴンは配信版でも量子化メッシュ（`dragon.bin`）を使っています。頂点は1つも
削っていないため見た目は原本と同等で、6.1MB→1.7MB になります。作り直すときは
`tools/fetch-source-assets.sh` で原本を取得してから `tools/pack-dragon.mjs` を実行します。

## 操作方法

| 場所 | 操作 | 動作 |
|---|---|---|
| 一覧カード | **クリック / タップ** | そのデモを全画面で開く |
| 一覧カード | ドラッグ | その場でデモを操作（視点回転・インク注入など） |
| 一覧カード | ピンチ | ズーム |
| 全画面 | タップ | デモ固有の切替・アクション（下表の「インタラクション」） |
| 全画面 | ドラッグ | 視点回転・つかむ・かき混ぜる |
| 全画面 | ホイール / ピンチ | ズーム |
| 全画面 | ← → / Esc | 前後のデモへ移動 / 閉じる |

一覧では縦スワイプをページスクロールに残しているため、モバイルでもスクロールを妨げません。

## アーキテクチャ

- **単一WebGLコンテキスト共有**: 全面を覆う canvas 1枚に対し、各カードのDOM位置へ
  `viewport/scissor` を合わせて全デモを描画（three.js "multiple elements" 方式）。
  WebGLコンテキスト数の上限を回避します。canvas は文書内 `absolute` に置き、
  毎フレーム `transform` でビューポートへ追従させることでスクロール時のズレを防いでいます。
- **画面外自動停止**: IntersectionObserver で見えていないカードの更新・描画をスキップ。
- **遅延初期化**: カードが視界に近づいたものから1件ずつ順番に初期化。
  Rapier（約2MB WASM）は剛体デモ初回表示時に動的インポート。
- **品質2段階**: グリッド表示はプレビュー品質（DPR≤1.5・低解像度シム）、
  全画面表示でフル品質（DPR≤2・シム解像度/反復回数/シェル数を引き上げ）。
- **GPGPU**: 流体・水面・パーティクルはピンポンFBO（HalfFloat）で状態をGPU上に保持。

```
  core/    エンジン（scissor描画・ポインタルーティング・アセットキャッシュ・GPGPUヘルパー）

  main.ts  デモレジストリ・カードUI・全画面ビューア
public/assets/  glTFモデル・HDRI（下記クレジット参照）
```
